# 榜单服务 — ECS 部署指南

> 架构：钉钉 AI 表格 →（每日 8:30 定时任务）`push_leaderboard.py` 推送 → ECS 后端入库（SQLite）→ 前端自动展示。
> 页面部署一次后不再重新发布，URL 永久固定。

## 一、后端部署（ECS，Docker）

```bash
# 1. 上传代码（或 git clone 仓库后进入该目录）
scp -r "数字化/钉钉/榜单服务" root@<ECS_IP>:/opt/leaderboard
ssh root@<ECS_IP>
cd /opt/leaderboard

# 2. 安装 Docker（已装跳过）
curl -fsSL https://get.docker.com | sh && systemctl enable --now docker

# 3. 生成推送令牌并启动（记住令牌，推送端要用）
export LEADERBOARD_TOKEN=$(head -c 24 /dev/urandom | base64 | tr -d '/+=')
echo "LEADERBOARD_TOKEN=$LEADERBOARD_TOKEN" > /opt/leaderboard/.env
docker compose --env-file .env up -d --build

# 4. 验证
curl http://127.0.0.1:8300/healthz          # → {"ok": true}
```

开机自启：`restart: unless-stopped` 已由 Docker 保证。

### 更新版本

```bash
cd /opt/leaderboard
git pull            # 或重新 scp
docker compose --env-file .env up -d --build
```

回滚：`docker run -d ... digital-ops/leaderboard:<旧版本tag>`（需要构建时打 tag，见 CI 部分）。

## 二、对外访问

内部分享用 IP:8300 即可。如需域名/HTTPS，前置 nginx：

```nginx
server {
    listen 80;
    server_name leaderboard.example.com;
    location / {
        proxy_pass http://127.0.0.1:8300;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

安全组：放开 8300（或 nginx 的 80/443）给公司出口 IP 段，不必对全公网开放。

## 三、数据推送端（本机 / 千问办公定时任务）

本机（Windows，推送脚本所在机器）设置环境变量后由定时任务调用：

```bash
# 一次性配置（写入用户环境变量）
setx LEADERBOARD_URL "http://<ECS_IP>:8300"
setx LEADERBOARD_TOKEN "<与后端一致的令牌>"

# 手动验证一次
"%USERPROFILE%\miniconda3\python.exe" "D:\repos\digital-ops\数字化\钉钉\杭州日报机器人\push_leaderboard.py"
# → OK: 已推送 9月4日 快照 (24人, 4/24 工作日) → http://...
```

千问办公定时任务（08:30 榜单任务）执行顺序：
1. `push_leaderboard.py`（推送数据到 ECS，替代原"生成HTML→复制→发布"三步）
2. 浏览器访问 `http://<ECS_IP>:8300` 验证页面正常即可，无需发布操作

> 推送脚本与后端共用令牌；令牌只存在环境变量/.env 中，不入 git。

## 四、数据与备份

- SQLite 位于 `./data/leaderboard.db`（volume 挂载，容器重建不丢）
- 每日一个快照（按 month+stat_date 幂等覆盖），`/api/history` 提供当月趋势
- 备份：`docker run --rm -v /opt/leaderboard/data:/data -v /root/backup:/bak alpine \
  sh -c "cp /data/leaderboard.db /bak/leaderboard-$(date +%F).db"`（可加 crontab）

## 五、故障排查

| 现象 | 排查 |
|---|---|
| 页面"暂无数据" | 本机先手动跑 push_leaderboard.py 看退出码 |
| 推送 401 | 两端 LEADERBOARD_TOKEN 不一致（注意 ECS .env 与本机 setx 后重开终端） |
| 推送失败连不上 | ECS 安全组 8300 是否放通本机出口 IP；`curl http://ECS_IP:8300/healthz` |
| 容器挂了 | `docker logs leaderboard`；`docker compose --env-file .env up -d` 重启 |
| 月份不符退出码 3 | 换月了，建新表更新 config.json 后重试 |

## 六、与 CI/CD 的衔接（上 GitHub 后）

本仓库 `.github/workflows/ci.yml` 已做语法检查。可扩展：

```yaml
  build:
    needs: lint
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Build & push image
        run: |
          docker build -t <ACR地址>/digital-ops/leaderboard:${{ github.sha }} \
            "数字化/钉钉/榜单服务"
          docker push <ACR地址>/digital-ops/leaderboard:${{ github.sha }}
```

ECS 端 `docker compose pull && up -d` 即完成发布。
