## §5 铁律与已知坑

**代码/库**
- `db.connect` 是 `DictCursor`：`dict(fetchall())` 会把单行两列捏成 `{'status':'COUNT(*)'}` 假行 → 必须按键取值
- `sync_dataset_summary` 列名是 `raw_records_written`（不是 `records_written`）
- `sync_runs` / `robot_outbox` 时间列存 **UTC**
- pymysql 下 LIKE 字面量必须 `%%` 转义

**部署**
- `docker compose restart` **不应用 env_file 变更** → 改了 app.env 必须 `up -d` 重建
- `docker cp` 对 scheduler 容器经常报 no such directory → 用 `cat file | docker exec -i <c> ...` 管道注入
- `/opt/dops/live` / repo 多为只读挂载，写文件先确认挂载属性

**云 API / 网络**
- 本机 `curl` 是 PowerShell 的 `Invoke-WebRequest` 别名 → 公网验证用 `curl.exe`
- ctyun-cli 的 `--securityGroupRules` JSON 在 PowerShell 会被吞引号 → **必须写成 .bat 走 cmd**（已固化在 `tools/sg_allow_office_ip.bat`）
- 端口 `range` 是单值 `"18080"`，不是 `"18080/18080"`
- 天翼云对未 ICP 备案的 80/443 在运营商层拦截（SG 全放也不通）→ 榜单临时走 8300

**业务口径（不要顺手改）**
- AI 表数据是权威口径：渠道日报 MTD = 自然日月累计 ÷ 月目标（不是按已过工作日）
- 名称含「合计」的行必须排除；offline_all 所有维度锚定 `business_date-1`
