## 待办清单（按顺序）

### 1. 提供 corpId（2 分钟）

钉钉开发者后台首页可见企业 corpId（非敏感信息）。发给开发侧，写入云上
`/opt/dops/app.env` 的 `KB_DINGTALK_CORPID=` 一行后重建 bi-web
（`docker compose -f /opt/dops/docker-compose.dops.yml up -d bi-web`）。

### 2. HTTPS 证书（前置依赖：H5 微应用首页要求 https）

证书签发底座已就绪（nginx 已配 acme webroot），执行：

```bash
# 云上 dops-app 宿主机
certbot certonly --webroot -w /opt/dops/nginx/acme -d dt.yyhlzj.com
```

然后在 nginx 加 443 server 段（证书路径 `/etc/letsencrypt/live/
dt.yyhlzj.com/`），80 保留（acme 验证需要）并跳转 443。nginx 容器需加
证书目录挂载（compose 里 dops-nginx 加 `- /etc/letsencrypt:/etc/letsencrypt:ro`，
改 compose 后 `up -d dops-nginx`）。

### 3. 开发者后台配置小易应用（10 分钟）

1. 应用能力 → 添加「**H5 微应用**」，首页地址填
   `https://dt.yyhlzj.com/kb/`；
2. 安全域名（JSAPI 安全域名）加 `dt.yyhlzj.com`；
3. 权限管理：确认有「通讯录个人信息读」（免登换 userid 用）。

## 排障速查

| 现象 | 排查 |

| 答案全是「查询出了点问题」 | `docker logs dops-bi-web` 看 `kb web: answer failed` 行 |

| 免登报错 | corpId 没配/配错；H5 微应用没发布 |
