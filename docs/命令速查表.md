### 公共数据管道（运维手动执行，只写本地测试库）

manifest 与凭据文件放仓库目录之外，经环境变量挂载；各线独立 run_id、独立成败。

```bash
# 按线同步（sync-dingtalk 只挂钉钉凭据，sync-wdt 只挂 WDT 凭据）
PUBLIC_DATA_LIVE_MANIFEST_PATH=/abs/manifest.json PUBLIC_DATA_LIVE_CREDENTIALS_PATH=/abs/creds.json \
docker compose -f docker-compose.integration.yml --profile live-sync-dingtalk run --rm sync-dingtalk
PUBLIC_DATA_LIVE_MANIFEST_PATH=/abs/manifest.json PUBLIC_DATA_LIVE_CREDENTIALS_PATH=/abs/creds.json \
docker compose -f docker-compose.integration.yml --profile live-sync-wdt run --rm sync-wdt

# 提取层：本地 raw → 业务表（不读源、不挂凭据）
docker compose -f docker-compose.integration.yml --profile extract run --rm extract-mart

# Nacos 注册/配置中心 + 管道种子导入（宿主机执行需指向映射端口）
docker compose -f docker-compose.integration.yml --profile nacos up -d nacos
PUBLIC_DATA_NACOS_SERVER=localhost:8848 \
python -m common.public_data.cli publish-pipelines --seed docker/integration/pipelines.seed.yaml --if-missing
```

业务线容器（`robot` / 榜单 / `dingtalk-gateway`）切换仍未提供命令入口；不得据此修改 cron、计划任务或任何外部调度。

## 八、常见排查

| 现象 | 命令/检查项 |
|------|------------|
| 群里没收到 | 先看脚本输出；Windows 控制台乱码时加 `PYTHONIOENCODING=utf-8` |
| 测试群 400 | 检查 `common/test_groups.json` 的 `robotCode` / `openConversationId` |
| 渠道机器人「未能识别销售额字段」 | 运行 `discover_tables.py` 确认字段名，或在 `config.json` 的 `fields.sales` 显式指定 |
| 单元测试发现 0 个 | 用 `python -m unittest discover -s tests -t . -v`，不要省略 `-t .` |

## 九、BI 看板（bi-web）

```powershell
# 历史月回补（重跑 extract 同步）后，手动清该月冷缓存（示例 2026-08，按需替换月份）
docker exec public-data-integration-redis-1 sh -c "redis-cli --scan --pattern 'biweb:card:*:2026-08' | xargs -r redis-cli UNLINK"

# 未启用 Redis（PUBLIC_DATA_REDIS_URL 为空 = 进程内缓存后端）时：重启即清
docker restart public-data-integration-bi-web-1
```

> 背景：卡片缓存冷热分层，封月键为 `biweb:card:*:{月份}`、冷 TTL 86400s。
> 回补后不清也会随 TTL 自然过期（最长延迟 24h），手动清理只是立即生效。
