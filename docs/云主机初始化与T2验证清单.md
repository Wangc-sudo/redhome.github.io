## P2. Docker 初始化（三台相同）

```bash
# 1. 安装（用国内镜像源，Ubuntu 24.04）
apt-get update
apt-get install -y ca-certificates curl gnupg
install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://mirrors.aliyun.com/docker-ce/linux/ubuntu/gpg | gpg --dearmor -o /etc/apt/keyrings/docker.gpg
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/docker.gpg] https://mirrors.aliyun.com/docker-ce/linux/ubuntu noble stable" > /etc/apt/sources.list.d/docker.list
apt-get update
apt-get install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

# 2. 日志轮转（方案 §2.4：json-file 10m×3）+ 镜像加速
cat > /etc/docker/daemon.json <<'EOF'
{
  "log-driver": "json-file",
  "log-opts": { "max-size": "10m", "max-file": "3" },
  "registry-mirrors": ["https://docker.m.daocloud.io"]
}
EOF
systemctl enable --now docker
systemctl restart docker

# 3. 验证
docker version
docker compose version
docker run --rm hello-world   # 拉不下来就换镜像加速器，不必死磕
```

## 常见坑

| 现象 | 原因 | 处置 |
|---|---|---|
| `redis-cli` 一直 hang | DCS 密码错或安全组未生效 | 先 `nc -zv dops-redis 6379` 区分网络/认证 |
| `time_zone` 显示 SYSTEM 且为 UTC | RDS 参数组默认值 | 控制台改参数组为 `+08:00`，动态生效无需重启 |
| docker pull 超时 | Docker Hub 直连受限 | 换 daemon.json 的 registry-mirrors（daocloud / 网易 / 中科大轮试） |
| apt 慢 | 默认源在海外 | 换 Ubuntu 国内源：`sed -i 's|//.*archive.ubuntu.com|//mirrors.aliyun.com|' /etc/apt/sources.list.d/ubuntu.sources` |
